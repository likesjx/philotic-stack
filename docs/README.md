# Philotic Stack Documentation

Welcome to the `philotic-stack` documentation directory. This repository contains both the new service-oriented architecture documents and historical documents from the legacy `zeroclaw` monolith.

## Directory Structure

The documents have been explicitly separated into two domain top-levels:

### 1. `philotic-stack/`

These are the most current and active architectural reflections, hand-off plans, and concepts regarding the Universal Materialization Mesh.

- **`architecture/`**: Handoff documents, Context Graph theories, and state plans (`philotic_handoff.md`, `veo3_video_concept.md`).
- **`planning/`**: Task lists, implementation plans, and walkthrough logs generated during the architectural decoupling.
- **`media/`**: Generated icons and system logos.

### 2. `legacy-zeroclaw/`

A perfect, historical snapshot of all Markdown playbooks, setup scripts, and references from the original `zeroclaw` monolithic repository, retained for context when porting over plugins and skills.

- **`architecture/`**: Old diagrams, system maps, and peripheral designs.
- **`build/`**: Setup instructions (Android, Arduino, Docker, etc.).
- **`runbooks/`**: Operational playbooks and troubleshooting guides.
- **`testing/`**: Audit logs, Qwen model test results, and snapshot reports.
- **`security/`**: Agnostic security policies, sandboxing techniques, and roadmaps.
- **`reference/`**: Deep context dictionaries on tools, channels, config schemas, and provider APIs.
- **`hardware/`**: Schematics and datasheets.
