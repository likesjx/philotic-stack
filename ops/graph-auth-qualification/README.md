# Synthetic Memgraph entry inventory — test only

This candidate adapts the previously passing authentication fixture at commit d0dd2a11d363124f0762b7fccaa20eac975a4bf8 and uses the same pinned Memgraph MAGE image and durability flags. On a fresh exclusive GitHub-hosted runner it creates one network-none container and synthetic administrator, acknowledges one fixed synthetic graph write, gracefully restarts, verifies that record and authentication, stops and verifies the exact container, then classifies the stopped data-directory entries. Fixed category/count output contains no names, data, credentials or link targets. Links are not followed. It then verifies exact owned cleanup and removes fixture scratch.

This test observes metadata only: it does not copy, omit or restore any entry and does not establish a backup procedure. Its one-node workload is smaller than the full hotel fixture, so absence of a special entry would not explain or disprove that fixture's result. An observed symlink target category is lexical only and does not establish safe resolution or permission to copy. Prior local socket bind was denied; socket classification is tested with fake metadata and no socket creation. No production data, keys, services, credentials or deployment are used.

The candidate requires exact reviewed source, the branch-scoped synthetic workflow, a fresh Linux runner with Docker, and normal access review. Unknown create, shutdown, inventory or cleanup is failure; an uncertain seed is never automatically retried. Hosted execution remains unqualified until the actual result and pinned image identity are checked. The first graph account is an administrator; this does not prove least privilege, full-stack restore, provider login, production capacity or production custody.
